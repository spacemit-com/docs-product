# V100 Computing Server C2201

Click to download **[V100 Computing Server C2201 Brief (PDF)]()**

**A reliable, high-performance platform for general-purpose computing**

## Overview

The C2201 is a 2U dual-socket rackmount server powered by SpacemiT. Designed for data centers, cloud and scientific computing, and mission-critical workloads, it balances compute performance, memory bandwidth, scalability, reliability, security, and ecosystem compatibility for easy deployment and management.

It bases on the RISC-V server-grade CPU V100, fully supports the RISC-V RVA23 Profile, and combines a dual-socket architecture, high clock speeds and core density, high-bandwidth DDR5 memory, and PCIe 5.0 I/O. It provides a high-performance, reliable, and scalable computing platform for data-intensive and high-concurrency workloads.

## Key Features

- **Full RISC-V Server Specification Compliance**

  Complies with relevant specifications, including the Server SoC, Server Platform, RVA23 Profile, BRS, and Security Model.

- **Data Center-Class Compute Performance**

  Supports up to two processors and 92 high-performance cores, with clock speeds up to 2.4 GHz and a per-core SPECint2006 score greater than 9.0/GHz.

- **High-Bandwidth DDR5 Memory**

  Supports 16 DDR5 channels, 1DPC, and mainstream DDR5 RDIMMs at up to 4800 MT/s and 307 GB/s.

- **Fine-Grained Memory Management**

  Supports multi-level arbitration, QoS policies, bandwidth control, and performance monitoring.

- **Server-Grade Virtualization**

  Supports Hypervisor 1.0, memory and interrupt virtualization, the standard Advanced Interrupt Architecture (AIA), and IOMMU-based device virtualization.

- **Data Center Security Architecture**

  Supports a hardware root of trust, secure boot, key and lifecycle management, secure debugging, trusted computing, and mainstream Chinese commercial cryptographic algorithms.

- **High Reliability**

  Provides RAS coverage for CPU, memory, PCIe, and power, plus redundant power supplies, hot-swappable fans, multiple RAID levels, and power-loss protection.

- **High-Speed Expansion**

  Provides 88 PCIe 5.0 lanes and supports GPU, NPU, and FPGA accelerators plus SAS/SATA and NVMe storage.
