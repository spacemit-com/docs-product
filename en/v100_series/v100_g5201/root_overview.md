# V100 Intelligent Computing Server G5201

Click to download **[V100 Intelligent Computing Server G5201 (PDF)](https://cdn-resource.spacemit.com/file/product/V100/g5201_brief_en.pdf)**

**High compute density, high energy efficiency AI computing engine**

## Overview

The G5201 is a next-generation 4U dual-socket, high-density rackmount intelligent computing server powered by SpacemiT's in-house-developed RISC-V server-grade CPU V100. Designed for large-model inference, scientific computing, AI computing centers, data centers, and government, finance, healthcare, and energy applications, it combines high compute density, scalability, security, and broad compatibility with China-developed hardware and software for easy deployment and centralized management.

This independently developed intelligent server supports coordinated operation and flexible expansion of up to eight PCIe air-cooled accelerator cards. High-speed GPU interconnects, large system memory, high-performance GPU memory, and efficient data processing support large-model inference, scientific computing, cloud computing, and virtualization. Compatible with multiple mainstream accelerators and operating systems, enabling a secure, efficient, and flexible heterogeneous computing platform.

## Key Features

- **High Compute Density**

  Supports a full configuration of eight PCIe air-cooled accelerator cards in 4U for AI inference and scientific computing.

- **High-Power Accelerator Support**

  Supports stable operation of a full configuration of eight accelerator cards with a TDP of 600 W each.

- **Large Memory Capacity and High Bandwidth**

  Provides 16 DDR5 DIMM slots, up to 2 TB of capacity, and eight-channel DDR5 memory at 4800 MT/s.

- **AMD Open-Source Ecosystem Compatibility**

  Supports multiple AMD GPU accelerators and the ROCm open-source ecosystem for easier AI and HPC deployment.

- **High-Speed GPU Interconnect**

  Provides up to 256 GB/s of GPU interconnect bandwidth for efficient multi-GPU computing.

- **Large-Capacity, High-Bandwidth GPU Memory**

  Supports high-capacity HBM3E memory with ultra-high bandwidth for large-model inference and HPC.

- **Flexible GPU Expansion**

  Supports flexible 2/4/8 GPUs interconnect configurations based on workload needs.

- **High-Speed Networking**

  Equipped with four 400GbE RoCE high-speed network cards, supporting RDMA RoCEv2
