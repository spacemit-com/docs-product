# V100 Storage Server S5236

Click to download **[V100 Storage Server S5236 (PDF)](https://cdn-resource.spacemit.com/file/product/V100/s5236_brief_en.pdf)**

**High-throughput, low-latency, high-capacity data storage hub**

## Overview

The S5236 is a 4U high-density rackmount storage server powered by SpacemiT's in-house-developed, RISC-V server-class V100 CPU. Designed for cloud computing and storage, AI computing centers, data archiving, backup and disaster recovery, and government and enterprise applications, it balances compute performance, storage capacity, scalability, reliability, compatibility with hardware and software, and energy efficiency for easy deployment and management.

This independently developed 4U dual-socket server uses high-performance V100 processors, eight-channel DDR5 memory at 4800 MT/s, 16 DIMM slots, and up to 2 TB of memory. PCIe 5.0 I/O and up to 36 drive bays support high-capacity storage and high-speed expansion. A 0°C to 40°C operating range and redundant power supplies and fans provide enterprise customers in cloud computing and cloud storage with a high-performance, reliable, scalable, and energy-efficient storage platform.

## Key Features

- **High-Capacity Storage Expansion**

  Provides 24 front and 12 rear 3.5-inch SATA bays plus two 2.5-inch SATA system-drive bays for high-density 4U storage.

- **High Performance and Standards Compliance**

  Uses two V100 processors with 92 CPU cores and supports the RISC-V RVA23 Profile and relevant Server SoC specifications for data-intensive workloads.

- **High Memory Bandwidth**

  Provides eight-channel DDR5 memory at 4800 MT/s and theoretical bandwidth of approximately 307 GB/s for concurrent and large-scale data processing.

- **Large Memory Capacity**

  Provides 16 DDR5 DIMM slots and up to 2 TB of memory for databases, virtualization, data analytics, and high-concurrency workloads.

- **RAS Reliability Design**

  Provides RAS features for processors, memory, PCIe, and system buses, with in-band and out-of-band management for stable 24/7 operation.

- **Hardware Virtualization Support**

  Supports CPU, memory, and I/O virtualization on mainstream platforms, providing isolated environments for cloud and multi-service resource pools.

- **Intelligent Management and Redundancy**

  Uses 1+1 redundant CRPS power supplies and N+1 redundant, hot-swappable fans, with BMC monitoring, remote KVM, and intelligent fan control for easier administration.

- **Mainstream Storage Ecosystem Compatibility**

  Compatible with mainstream operating systems and distributed storage software stacks for rapid plug-and-play deployment of large-scale storage solutions.
