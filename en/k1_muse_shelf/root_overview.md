# K1 MUSE Shelf Brief

**[PDF Version](https://cdn-resource.spacemit.com/file/product/K1/MUSE_shelf_brief_en.pdf)**

**RISC-V cloud computing power open for global developers**

**MUSE Shelf** is a RISC-V development server designed specifically for the developer community, offering comprehensive computing power, efficient operations, high-speed connectivity, and intelligent management. The application platform is powered by Bianbu Cloud services, offering a highly available, scalable, and high-performance distributed cloud environment for RISC-V-based application development and adaptation.

**MUSE Shelf** aims to provide global developers with RISC-V computing instances, supporting features like remote desktop, remote compilation, one-click flashing, and one-click application installation, allowing developers to leverage RISC-V processing power and engage in creative development anytime and anywhere.

## Key Features

- **High-Density RISC-V Compute Cluster**
  Integrates 80 SpacemiT RISC-V 8-core processors, delivering massive parallel compute for development and validation

- **Modular Blade Architecture**
  2/4-blade design for flexible deployment, fast maintenance, and scalable expansion

- **Standard Server Form Factor**
  Built on a 2U server platform for easy data center integration and large-scale operations

- **Flexible Debugging Support**
  Supports SSH, UART, ADB, and other methods across different development stages

- **Remote Development Capability**
  Enables file transfer and VNC/RDP access for a complete remote development experience

- **Remote Flashing & System Management**
  Supports Fastboot flashing and remote power control for efficient device management and system updates
