# K1 MUSE Pi Pro Brief

**[PDF Version](https://cdn-resource.spacemit.com/file/product/K1/MUSE_Pi_Pro_brief_en.pdf)**

**Compact and efficient, powering the future of AI and IoT**

**K1 MUSE Pi Pro** is a single-board computer that integrates a high-performance RISC-V 8-core processor, storage, I/O, and expansion capabilities into a credit card-sized 1.8-inch board. With UEFI support, open-source resources, and strong compatibility, it is ideal for AI applications, robotics, education, and IoT scenarios requiring efficient power and compact form.

## Key Features

- **Compact Design**
  Credit card-sized 1.8-inch single-board computer  

- **UEFI Support**
  Flexible boot media selection and system configuration  

- **Fully Open Source**
  Open board-level, mechanical, and software design resources with application guidance  

- **GRUB Boot Support**
  Multi-OS installation with user-selectable boot options  

- **Domestic Innovation**
  Locally developed solution ensuring supply continuity  

- **Standard I/O Expansion**
  miniPCIe and M.2 interfaces compatible with mainstream components  

- **High Reliability**
  Structural protection, ESD resilience, and EMC compliance
