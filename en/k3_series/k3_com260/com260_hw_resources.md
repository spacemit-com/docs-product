# K3 CoM260 Development Kit Hardware Design Resources

This section provides the official hardware design resources for the **K3 CoM260 Development Kit**.  
Download the following files to support hardware development, PCB design, and system integration.

- [K3-CoM260 Core Board Schematic (PDF)](https://cdn-resource.spacemit.com/file/product/K3/k3_com260_hw/k3-com260_p1_lp5315b_32x2_v03_20260312.pdf)
