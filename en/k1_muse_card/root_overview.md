# K1 MUSE Card Brief

**K1 MUSE Card** is a compact, high-efficiency single-board computer (SBC) powered by the SpacemiT 8-core RISC-V AI CPU.

- 8-core 64-bit RISC-V high-performance processor from SpacemiT
- Integrated 2.0 TOPS @ INT8 AI compute
- 32-bit LPDDR4X memory support
- Dual-display support via MIPI DSI & HDMI, FHD resolution
- 4K video encoding and decoding
- 1 x USB 3.0, 1 x USB 2.0, 40-pin standard GPIO header
- Dual M.2 2242 SSD slots
- Gigabit RJ45 Ethernet
- USB Type-C power input

## Specifications

| Module | Description |
| --- | --- |
| Processor | SpacemiT M1, 8-core 64-bit RISC-V processor with integrated 2.0 TOPS AI performance |
| Display | HDMI Type-A, up to 1080P @ 60 Hz<br>4-lane MIPI DSI FPC connector, up to 1080P @ 60 Hz |
| Memory | LPDDR4X, 2400 MT/s, 8 GB or 16 GB options |
| Local Storage | SPI NOR Flash, 64 Mb |
| Storage Expansion | 2 x M.2 2242 M-Key connectors supporting 2 NVMe SSDs<br>TF card slot with UHS-II mode support |
| Wired Network | 1 x Ethernet, RJ45, 10/100/1000 Mbps adaptive |
| Audio | 3.5 mm combo audio jack (headset) |
| USB | 1 x USB 3.0 Type-A host + 1 x USB 2.0 Type-A host<br>1 x USB 2.0 Type-C device, supports 12 V @ 3 A power input |
| Debug / GPIO | 40-pin standard GPIO header with 3 side buttons for hardware reset, power on/off, and firmware flashing |
| MIPI Interfaces | 1 x 4-lane MIPI DSI<br>2 x 4-lane MIPI CSI, supporting "4+4" or "4+2+2" lane configurations |

| Operating System | Supports Bianbu Desktop, Bianbu NAS, Ubuntu, OpenKylin, Deepin, Fedora, and more |
| Power Input | USB PD 3.0 |
| Reliability | Peripheral ESD protection: ±4 kV (contact), ±8 kV (air)<br>Consumer grade: -20 °C to 70 °C; Industrial grade: -40 °C to 85 °C |
