# K1 RISC-V 集群服务器 简介

**K1 RISC-V 集群服务器** 是专为开发者群体设计的RISC-V开发服务器，具有全面计算、高效运维、高速互联、智能管理的特点；应用平台采用BianbuCloud服务，提供高可用、强拓展、高性能的分布式云平台，提供基于RISC-V平台的应用开发或适配。

**K1 RISC-V 集群服务器** 旨在为全球开发者提供RISC-V计算实例，支持远程桌面、远程编译、一键刷机、一键应用安装等功能，让开发者可以随时随地的使用RISC-V算力并做创意开发。

- 集成80个进迭时空RISC-V八核中央处理器
- 模组化2/4刀片式设计，灵活部署和维护
- 标准服务器框架（2U）设计
- 支持SSH/UART/ADB调试
- 支持远程文件上传、下载
- 支持VNC/RDP投屏
- 支持远程Fastboot刷机
- 支持远程上下电操作
