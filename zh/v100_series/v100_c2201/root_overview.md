# V100 计算服务器 C2201

点击下载 **[V100 计算服务器 C2201 产品简介（PDF）](https://cdn-resource.spacemit.com/file/product/V100/c2201_brief_zh.pdf)**

**高性能、高可靠、全场景覆盖的通用算力底座**

## 概述

C2201 是进迭时空基于自研打造的 2U 双路机架式服务器，适用于数据中心、云计算、科学计算及行业关键业务等场景。产品在计算性能、内存带宽、扩展能力、可靠性、安全性及软硬件生态兼容等方面实现均衡，便于部署与管理。

作为一款自主研发的 2U 双路机架式服务器，C2201 基于 RISC-V 服务器级 CPU V100，全面兼容 RISC-V RVA23 Profile，整机支持双路处理器部署。服务器具备高主频、高核心密度和高带宽 DDR5 内存，并支持 PCIe 5.0 高速 I/O 扩展，可满足数据密集型应用与高并发业务需求，为数据中心及行业用户提供高性能、高可靠、易扩展的算力平台。

## 特性

- **完整符合 RISC-V 服务器规范**
  
  遵循 Server SoC、Server Platform、RVA23 Profile、BRS 及 Security Model 等相关规范。

- **数据中心级计算性能**
  
  整机最多配置 2 颗芯片、共计 92 个高性能核心；单颗芯片主频 2.4 GHz，单核 SPECint2006 > 9.0/GHz。

- **高带宽 DDR5 内存**
  
  整机支持 16 个 DDR5 通道、1DPC 和主流 DDR5 RDIMM，速率达 4800 MT/s，最大带宽 307 GB/s。

- **精细化内存管理**
  
  支持多级仲裁、QoS 策略、带宽限制和性能监控。

- **服务器级虚拟化**
  
  支持 Hypervisor 1.0、内存与中断虚拟化、标准 AIA 中断控制器，以及基于 IOMMU 的外设虚拟化。

- **数据中心级安全架构**
  
  支持硬件信任根、安全启动、密钥与生命周期管理、安全调试、可信计算及主流国密算法。

- **高可靠性设计**
  
  覆盖 CPU、内存、PCIe 和电源的 RAS 机制，支持冗余电源、热插拔风扇、多级 RAID 及断电保护。

- **高速扩展能力**
  
  整机提供 88 条 PCIe 5.0 Lane，兼容 GPU、NPU、FPGA 加速卡及 SAS/SATA、NVMe 存储设备。
