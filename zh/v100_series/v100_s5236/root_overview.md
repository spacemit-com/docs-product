# V100 存储服务器 S5236

点击下载 **[V100 存储服务器 S5236 产品简介（PDF）]()**

**高吞吐、低时延、大容量的数据存储中枢**

## 概述

S5236 是进迭时空基于自研 RISC-V 服务器级 CPU V100 打造的 4U 高密度机架式存储服务器，适用于云计算、云存储、智算中心、数据归档、备份容灾等场景。产品在计算性能、存储容量、扩展能力、可靠性、能耗控制等方面实现均衡，便于部署与管理。

作为一款自主研发的 4U 双路机架式服务器，S5236 基于 V100 高性能处理器，支持 8 通道 4800 MT/s DDR5 内存技术，配备 16 个 DDR5 内存插槽，最大支持 2 TB 内存扩展。服务器支持 PCIe 5.0 高速 I/O，并提供多达 36 个硬盘槽位，满足海量数据存储与高速扩展需求。产品支持 0℃～40℃标准工作温度，并采用冗余电源和风扇设计，为云计算、云存储及政企客户提供高性能、高可靠、易扩展的绿色存储平台。

## 特性

- **超大存储容量扩展**

	支持前置 24 个 3.5 英寸 SATA 盘位、后置 12 个 3.5 英寸 SATA 盘位，并预留 2 个 2.5 英寸 SATA 系统盘位，在 4U 空间内实现高密度本地存储。

- **高性能与标准兼容**

	搭载两颗 V100 处理器，共计 92 个 CPU 核心，兼容 RISC-V RVA23 Profile 及 Server SoC 相关规范，满足数据密集型业务对计算性能的需求。

- **高速内存带宽**

	采用 8 通道 4800 MT/s DDR5 内存技术，理论内存带宽最高约 307 GB/s，提升多任务并发和大规模数据处理效率。

- **大容量内存扩展**

	配备 16 个 DDR5 内存插槽，最大支持 2 TB 内存扩展，满足数据库、虚拟化、数据分析及高并发业务对大容量内存的需求。

- **RAS 可靠性设计**

	围绕处理器、内存、PCIe 和系统总线等关键部件提供可靠性、可用性与可维护性设计，结合带内外管理能力，提升服务器 7×24 小时连续运行的稳定性。

- **硬件虚拟化支持**

	支持 CPU、内存和 I/O 虚拟化能力，可适配主流虚拟化平台，为云计算和多业务资源池提供隔离运行环境。

- **智能运维与冗余设计**

	采用标准 CRPS 1+1 冗余电源和 N+1 冗余热插拔风扇，支持 BMC 远程监控、远程 KVM 及风扇智能调速，降低运维复杂度。

- **兼容主流存储生态**

	兼容主流操作系统，适配分布式存储软件栈，海量存储方案快速部署、即插即用。
