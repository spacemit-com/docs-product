# K1 MUSE BOOK 简介

**[PDF 版本](https://cdn-resource.spacemit.com/file/product/K1/MUSE_book_brief_zh.pdf)**

**K1 MUSE BOOK** 是一款 RISC-V 笔记本电脑，搭载了进迭时空八核 RISC-V 芯片 M1，预装自研操作系统 Bianbu，自带进迭时空 AI 开发套件，可无缝迁移基于 ONNX RunTime 开发的 AI 工程，旨在为所有 RISC-V 的热爱玩家、AI 开发者、技术爱好者、研究人员等提供更高效便捷的 RISC-V 开发平台。

- 基于进迭时空 RISC-V 八核高性能中央处理器  
- 基于 M1 2.0T 原生 AI 算力，可支持从传统卷积到 Transformer 模型的部署，包含自然语言理解、智能语音、多模态等，其中大语言模型可支持从 0.5B 到 8B 的模型  
- 配备目标识别，简单大模型问答等 demo  
- 支持 4K H.265/H.264/VP9/VP8 等编解码格式  
- 支持 3D 图像引擎，OpenCL 3.0/OpenGLES 3.2/Vulkan 1.3  
- 含开发者接口：UART TX&RX/GPIO/PWM/3.3V/GND 信号，同时配套杜邦开发线，提供开发者容器，实现开发环境简单部署
